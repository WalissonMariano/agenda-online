# Agenda Online — comandos úteis

## Setup
cp .env.example .env
npm install

## Executar a API
npm run start
npm run start:dev
npm run start:debug
npm run build
npm run start:prod

## Migrations
npm run migration:run
npm run migration:revert
npm run migration:generate

## Seed / reset demo
npm run seed
npm run db:demo-reset

## Qualidade de código
npm run lint
npm run format
npm run build

## Testes
npm test
npm run test:watch
npm run test:cov
npm run test:e2e

## Nest CLI (gerar módulo / recurso)
npx nest g module nome-do-modulo
npx nest g controller nome-do-modulo
npx nest g service nome-do-modulo
npx nest g resource nome-do-modulo

## Dependências / segurança
npm audit
npm outdated
